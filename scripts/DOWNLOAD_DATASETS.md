# Optional full dataset setup

The submission already contains a small local demo catalog and visual look boards. You do not need a full dataset to run the app.

For experimentation, download the external datasets from their official pages:

1. Fashion Product Images (Small):
   https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-small
2. Polyvore outfit data:
   https://github.com/xthan/polyvore
3. DeepFashion:
   https://mmlab.ie.cuhk.edu.hk/projects/DeepFashion.html

Do not place a full external dataset inside the hackathon ZIP unless its license explicitly permits redistribution.
